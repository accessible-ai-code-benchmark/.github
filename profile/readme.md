# Accessible AI Code Benchmark

Accessible AI Code Benchmark is the home of open and neutral evaluation of the way AI handles accessibility. The aim is to create reliable, repeatable, and scalable benchmarks to help the web community make informed decisions about the use of AI in accessibility.

* [Code of Conduct](https://github.com/accessible-ai-code-benchmark/docs/blob/main/policies/code-of-conduct.md)
* [AI Code of Conduct](https://github.com/accessible-ai-code-benchmark/docs/blob/main/policies/ai-code-of-conduct.md)

## Roles

### Project Owners

The Project Owners are [TetraLogical](https://tetralogical.com) and [Microsoft](https://microsoft.com).

### Steering Committee

The Steering Committee has ultimate responsibility for the project. It consists of representatives appointed by the Project Owners.

Steering Committee composition:

* 2 representatives from TetraLogical appointed by TetraLogical
* 2 representatives from Microsoft appointed by Microsoft
* 1 independent representative appointed jointly by TetraLogical and Microsoft

Steering Committee members are chosen based on their ability to advance the project's mission and participate constructively in the project's governance.

Responsibilities include:

* Define project vision and scope
* Appoint and remove maintainers
* Resolve disputes
* Approve governance changes
* Manage trademarks, branding, and project assets
* Represent the project externally

## Decisions

### Steering Committee

The Steering Committee makes decisions by consensus wherever possible, but a vote may be taken when:

1. Consensus has not been achieved despite reasonable good faith efforts
2. At least two members of the Steering Committee request a vote be taken

If a vote is required, each member of the Steering Committee has one vote. A majority is required for a vote to succeed.

For significant decisions, approval must include at least one representative of each of the Project Owners. 
Examples include:

* Substantial changes to the project's scope, objectives, or strategic direction
* Changes to the project's governance model, including the composition or responsibilities of the Steering Committee

Meetings where decisions are made must achieve quorum. This means that a majority of the Steering Committee must be present, including at least one representative of each Project Owner.

### Maintainers

The Maintainers make decisions by consensus wherever possible, but a vote may be taken when:

1. Consensus has not been achieved despite reasonable good faith efforts
2. At least two Maintainers request a vote be taken

If a vote is required, each Maintainer has one vote. A majority is required for a vote to succeed.
